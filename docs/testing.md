# Проверка проекта

Документ описывает, что проверять после изменений. Команды запуска и сборки — в [README.md](../README.md).

## Автоматические проверки

Перед завершением изменений выполните проверки из README:

- линтинг;
- проверку TypeScript;
- production-сборку.

CSS-изменения также должны проходить production-сборку.

## Ручные сценарии

### Инициализация

- Очистите `localStorage` и перезагрузите страницу.
- Должно открыться модальное окно создания сеттинга.
- Поле названия сеттинга должно быть в фокусе.
- Можно создать два хороших, два плохих или разные по типу периода.
- После создания название появляется в шапке, периоды отображаются на графе.

### Автосохранение

- Создайте сеттинг, периоды, событие и сцену.
- Перезагрузите страницу.
- Модальное окно создания не должно появляться.
- Название, периоды, события и сцены должны восстановиться.
- Удалите карточку — сохранение должно обновиться.
- Нажмите сброс — состояние и `localStorage` должны очиститься.

### Периоды

- Кнопка добавления периода есть только между существующими периодами.
- После последнего периода добавить новый нельзя.
- Новый период получает тип, противоположный предыдущему.
- При вставке в середину чередование последующих периодов сохраняется.
- При редактировании периода можно изменить название и тип вручную.

### События и сцены

- Событие добавляется нижней кнопкой периода.
- Дополнительное событие добавляется нижней кнопкой события в тот же период.
- Сцена добавляется правой кнопкой события.
- Следующая сцена добавляется нижней кнопкой сцены в то же событие.
- Первая сцена отображается справа от события, следующие — под ней.
- При увеличении колонки сцен следующие события сдвигаются вниз.
- События одного периода остаются на одной вертикальной линии.

### Редактирование и удаление

- Кнопка редактирования открывает форму с заполненными названием и типом.
- Изменения применяются после сохранения.
- Кнопка удаления открывает подтверждение.
- Отмена удаления не меняет состояние.
- Удаление сцены удаляет только сцену.
- Удаление события удаляет событие и его сцены.
- Удаление периода удаляет период, события и сцены.

### Импорт и экспорт

- Экспорт предлагает имя файла на основе названия сеттинга.
- Имя файла можно изменить.
- Импорт валидного JSON восстанавливает название и дерево карточек.
- Импорт повреждённого JSON показывает ошибку и не меняет состояние.
- Старый файл без `settingName` импортируется с названием «Без названия».

### Сброс

- Кнопка сброса открывает подтверждение.
- Отмена сохраняет текущее состояние.
- Подтверждение очищает карточки, `localStorage` и открывает создание нового сеттинга.

### Тултипы

- Все кнопки имеют подсказки.
- Подсказка появляется с задержкой `1.5s`.
- Подсказка не перекрывается соседними карточками.
- Для кнопок в шапке и верхних углах карточек используется нижнее расположение подсказки.

### CSS и адаптивность

- Проверьте интерфейс при стандартном размере шрифта.
- Проверьте при увеличенном размере корневого шрифта.
- Проверьте ширину около `620px`: начальные периоды должны переходить в одну колонку.
- Убедитесь, что карточки, сцены и подсказки не выходят за пределы контейнера.
- Проверьте, что цвета, градиенты и тени соответствуют токенам из [style.md](./style.md).
