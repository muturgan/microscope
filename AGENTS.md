# AGENTS.md

Навигация по документации проекта Microscope для AI-агентов и разработчиков. Не читайте все документы сразу — используйте матрицу задач ниже.

## Что читать и когда

| Документ | Когда читать |
| --- | --- |
| [README.md](./README.md) | Установка, локальный запуск, сборка и команды проверок |
| [docs/arch.md](./docs/arch.md) | Перед изменением технической архитектуры, stores, React Flow, компонентных границ, сохранения или браузерных API |
| [docs/domain.md](./docs/domain.md) | Перед изменением поведения карточек, иерархии период → событие → сцена, правил kind, добавления, редактирования или удаления |
| [docs/storage.md](./docs/storage.md) | Перед изменением localStorage, JSON-формата, импорта/экспорта, валидации или миграций состояния |
| [docs/stack.md](./docs/stack.md) | Перед добавлением/обновлением зависимостей, проверкой версий и уточнением API библиотек |
| [docs/style.md](./docs/style.md) | Перед изменением CSS, вёрстки, дизайн-токенов, единиц, тултипов и визуальных состояний |
| [docs/testing.md](./docs/testing.md) | Перед проверкой изменений и для выбора ручных сценариев |
| [docs/struct.md](./docs/struct.md) | При первом знакомстве и для поиска файлов или каталогов |

## Матрица «задача → документы»

| Задача | Что читать |
| --- | --- |
| Новая фича карточек или изменение поведения | `arch.md`, `domain.md`, `struct.md` |
| Изменение графа или позиционирования периодов | `arch.md`, `domain.md`, `style.md` |
| Изменение localStorage, JSON, импорта или экспорта | `arch.md`, `storage.md`, `stack.md` при работе с API |
| Изменение CSS, карточек или модалок | `style.md`, `struct.md` |
| Добавление или обновление зависимости | `stack.md`, при влиянии на API — `arch.md` |
| Исправление бага | `struct.md`, затем профильный документ по области |
| Финальная проверка | `testing.md`, команды из `README.md` |

## Рекомендуемый порядок работы

1. Определите тип задачи по матрице.
2. Прочитайте только профильные документы.
3. Для команд запуска и проверок используйте [README.md](./README.md).
4. Для навигации по коду используйте [docs/struct.md](./docs/struct.md).
5. Перед уточнением API библиотек сверьтесь с версиями в [docs/stack.md](./docs/stack.md), чтобы не использовать документацию другой версии.

## Критичные инварианты

Краткие ссылки без дублирования деталей:

- React Flow-геометрия должна быть согласована с CSS: [arch.md](./docs/arch.md), [style.md](./docs/style.md).
- Формат состояния версионируется и валидируется: [storage.md](./docs/storage.md).
- Бизнес-правила карточек и каскадного удаления: [domain.md](./docs/domain.md).
- Все интерфейсы именуются с префиксом `I`: [arch.md](./docs/arch.md).
- CSS-токены, единицы и тултипы: [style.md](./docs/style.md).
- Проверки и ручные сценарии: [testing.md](./docs/testing.md).

## Definition of Done

Изменение считается завершённым, если:

- поведение реализовано и соответствует `domain.md`;
- архитектура не противоречит `arch.md`;
- формат хранения не сломан и соответствует `storage.md`;
- стили соответствуют `style.md`;
- выполнены автоматические проверки из `README.md`;
- пройдены релевантные ручные сценарии из `testing.md`;
- обновлены документы, если изменились правила, формат, зависимости или структура файлов.

## Границы документов

- `README.md` — только запуск, сборка и команды.
- `docs/stack.md` — только версии технологий и библиотек.
- `docs/arch.md` — технические архитектурные решения.
- `docs/domain.md` — бизнес-правила и поведение карточек.
- `docs/storage.md` — формат и сохранение состояния.
- `docs/style.md` — CSS и визуальные соглашения.
- `docs/testing.md` — проверки и ручные сценарии.
- `docs/struct.md` — структура файлов и каталогов.

## Поддержка документации

- Новый, удалённый или перемещённый файл → обновить [docs/struct.md](./docs/struct.md).
- Изменение архитектуры → обновить [docs/arch.md](./docs/arch.md).
- Изменение бизнес-правил → обновить [docs/domain.md](./docs/domain.md).
- Изменение localStorage или JSON → обновить [docs/storage.md](./docs/storage.md).
- Изменение версий технологий → обновить [docs/stack.md](./docs/stack.md).
- Изменение CSS-соглашений → обновить [docs/style.md](./docs/style.md).
- Новые сценарии проверки → обновить [docs/testing.md](./docs/testing.md).
