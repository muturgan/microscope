# Microscope

Редактор сеттингов: интерактивная шкала периодов с вложенными событиями и сценами. Приложение работает в браузере, автоматически сохраняет состояние в `localStorage` и поддерживает импорт/экспорт JSON.

## Требования

- Node.js актуальной LTS-версии;
- npm;
- современный браузер (желательно Chromium-совместимый для системного окна сохранения файла).

## Установка

```bash
npm ci --legacy-peer-deps
```

## Локальная разработка

1. Создайте файл `.env` в корне проекта:

   ```env
   VITE_PORT=7777
   ```

   Переменная `VITE_PORT` обязательна для запуска dev-сервера.

2. Запустите Vite:

   ```bash
   npm run dev
   ```

3. Откройте приложение:

   ```text
   http://localhost:7777
   ```

Если изменился порт в `.env`, используйте его в адресе.

## Сборка и проверки

```bash
npm run build   # проверка TypeScript и production-сборка в dist/
npm run preview # сборка и локальный предпросмотр
npm run lint    # ESLint по каталогу src
```

Для `npm run preview` также нужен `VITE_PORT` в `.env`.

Дополнительные команды:

```bash
VITE_PORT=7777 npm run force  # перезапуск Vite с очисткой кеша зависимостей
npm run build_env             # production-сборка с загрузкой переменных из .env
```
